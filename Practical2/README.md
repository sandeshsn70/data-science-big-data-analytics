# Practical 2: Data Wrangling II

## Objective
To create an Academic Performance dataset and perform:
1. Missing value and inconsistency handling
2. Outlier detection and treatment
3. Data transformation for normalization and scaling

## Dataset Description
The dataset includes student academic scores, attendance, and study hours.

## Techniques Used
- Mean & Median Imputation
- IQR Method for Outliers
- Log Transformation

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
