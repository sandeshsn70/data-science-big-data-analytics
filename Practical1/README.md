# 🧪 Practical 1: Data Wrangling using Python

## 📌 Objective
To perform **data wrangling and preprocessing** operations on an open-source dataset using Python, including data loading, inspection, cleaning, formatting, and conversion of categorical variables into numerical form.

---

## 📊 Dataset Used

### 🌸 Iris Flower Dataset
- **Source:** Kaggle (Open Source)  
- **Description:**  
  The Iris dataset contains measurements of iris flowers belonging to three species:
  - Iris-setosa  
  - Iris-versicolor  
  - Iris-virginica  

- **Attributes:**
  - Sepal Length  
  - Sepal Width  
  - Petal Length  
  - Petal Width  
  - Species  

---

## 🛠️ Tools & Libraries Used

- **Programming Language:** Python  
- **Libraries:** Pandas, NumPy  
- **Platform:** Jupyter Notebook / VS Code  

---

## 🔬 Steps Performed

1. Imported required Python libraries  
2. Loaded the Iris dataset into a Pandas DataFrame  
3. Displayed dataset structure and sample records  
4. Checked:
   - Data types  
   - Dataset dimensions  
   - Missing values  
5. Generated statistical summary using `describe()`  
6. Identified variable types (numerical & categorical)  
7. Converted categorical variables into numerical form  
8. Prepared dataset for further analysis and machine learning  

---

## 📈 Key Observations

- The dataset contains **150 records and 5 attributes**
- No missing values were found
- Numerical and categorical variables were clearly identified
- Dataset is clean and ML-ready after preprocessing
